🏸 Badminton Finder

This is a bookmarklet: a bookmark that runs a small script. It runs on the Gloucester booking site in your own browser and only reads availability. It doesn't log in and it doesn't book anything.

Set it up on a computer

  1. Show your bookmarks bar (Ctrl+Shift+B, or ⌘+Shift+B on a Mac).
  2. Drag the green 🏸 Badminton Finder button onto the bookmarks bar.

Set it up on a phone

  1. Tap Copy bookmarklet above.
  2. Bookmark this page, then edit that bookmark: name it Badminton and paste over the address.
  3. On iPhone the bookmark is under the book icon in Safari. In Chrome on Android, type Badminton in the address bar and tap the bookmark when it appears.

Use it

  1. Open flgloucester.gladstonego.cloud/book. If you tap the bookmark anywhere else, it offers to take you there.
  2. Tap the bookmark. Filter by venue, day, or evenings and weekends, then tap a time to open it in the normal booking page.

Why a bookmarklet? The booking site doesn't let other websites read its data, so the finder has to run on the booking site itself.
